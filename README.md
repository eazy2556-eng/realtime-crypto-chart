# 실시간 코인 차트

바이낸스 · 비트겟 · OKX의 현물과 USDT 무기한 선물을 트레이딩뷰처럼 보는 웹 페이지입니다.
서버 없이 브라우저가 각 거래소의 공개 시세 API에 직접 연결합니다. API 키나 로그인은 쓰지 않습니다.

- 열기: `binance-chart.html` (웹에서는 이 저장소의 GitHub Pages 주소)
- 지표·작도·관심 종목 설정은 기기마다 브라우저에 저장됩니다. 상단 "설정 옮기기"로 다른 기기에 링크·QR·파일로 옮길 수 있습니다.
- 자동 연동: 기기마다 GitHub 토큰(권한은 gist 하나)을 넣으면 내 계정의 비공개 gist 하나에 설정을 저장하고 기기끼리 맞춥니다. 토큰은 그 기기 브라우저에만 저장되고 GitHub 말고는 어디로도 보내지 않습니다.
- 휴대폰에서는 브라우저 메뉴의 "홈 화면에 추가"로 앱처럼 쓸 수 있습니다.

트레이딩뷰식 기능
- 가격 축의 봉 마감 카운트다운, 상단 시계(누르면 시간 단위별 봉 마감 시간과 시간대 선택: 내 기기·UTC 등)
- 차트 설정: 캔들 색(국내식 빨강 상승·파랑 하락 포함), 현재가 선, 보이는 구간 최고·최저, 1호가 선, 날짜 구분선, 거래량 프로파일, 격자·워터마크, 십자선 방식
- 가격 축: 일반·로그·퍼센트·100 기준, 뒤집기 (Alt+L · Alt+P · Alt+I)
- 차트 유형: 캔들·속 빈 캔들·하이킨 아시·바·라인·계단식·점 찍힌 라인·영역·베이스라인
- 종목 비교(다른 거래소 포함, 3개까지), 바 리플레이, 날짜로 이동(Alt+G), 전체 화면, 차트 이미지 저장
- 멀티 차트: 1·2·3·4칸 배치, 칸마다 종목·시간 단위·지표 따로, 종목·시간 단위·십자선 맞추기 (가로 900px 이상 화면)
- Shift+클릭 측정: 두 지점 사이 가격 차이·%·봉 수·기간·거래량 (다음 클릭이나 Esc로 사라짐)
- 계산기 탭(체결·호가 옆): 업비트 테더 시세 기준 테더 ⇄ 원화 교차 환산 (어느 칸에 넣든 다른 칸이 계산됨). 계산기 탭을 연 동안 업비트 공개 시세 API에서 테더 시세를 5초마다 자동으로 불러옴
- 가격 축 늘이기·줄이기: 가격 축을 위아래로 끌기 또는 휠, 더블클릭하면 자동 맞춤 (퍼센트 축·지표 창·휴대폰에서도 동작)
- 알림: 가격(관심 종목 밖 종목도) · 지표 선(값 또는 다른 선) · 작도 선(추세선·레이·채널 등) 돌파, 한 번만·봉마다·봉 마감 때, 소리·화면·브라우저 알림 (Alt+A). 차트가 열려 있어야 확인됨
- 신호 비서(오른쪽 아래 "신호" 탭): 지금 보는 종목을 차트 18개(1분 ~ 1주, 90분·3·6·8·12시간·2·3일 포함)로 계산합니다. 롱·숏마다 3단계 조건(이평 밀집·응축 / 30분·1시간 큰 파동 / 5·15분 저점 높임·다이버전스 + 교차)의 충족 여부와 근거 차트를 보여 줍니다. 차트별 표에는 스토캐스틱(5-3-3 · 10-5-5 · 20-10-10) 값, 골든·데드크로스, 응축, 다이버전스, 고승덕·백타(파동에너지) 자료의 쌍바닥·쓰리바닥·쌍봉·쓰리봉(스토캐스틱·가격·5선·20선·MACD)이 뜨고, "신호 글자 뜻"에 쉬운 설명이 있습니다. 신호 기록도 있습니다. "알림"을 켜면 5분봉이 마감될 때 세 단계가 새로 다 켜진 경우 알려 줍니다(같은 방향은 60분에 한 번). 과거 BTC 검증에서 이 알림은 하루 약 14번 울렸고, 알림 뒤 움직임은 무작위 시각과 같았습니다. 참고용입니다.
- 작도: 추세선·레이·연장선·화살표·수평선(가격 알림)·수평 레이·수직선·교차선, 평행 채널·회귀 추세·피치포크, 피보나치 되돌림·확장·시간대, 사각형·원·삼각형, 엘리엇 파동, 브러시·형광펜, 텍스트·가격 라벨·화살표 표시, 측정·롱/숏 포지션 · 도형 복제·잠금, 자석, Ctrl+Z

차트 그리기는 TradingView의 [Lightweight Charts](https://github.com/tradingview/lightweight-charts)(Apache-2.0)를 씁니다.
